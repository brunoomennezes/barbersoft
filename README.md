💈 BM Soft Barbearia

Sistema web moderno e responsivo desenvolvido para o gerenciamento completo de barbearias, oferecendo uma experiência fluida tanto para os clientes (agendamento online) quanto para os administradores (gestão de horários, catálogo de serviços e controle financeiro).

🚀 Funcionalidades do Sistema

👤 Área do Cliente
- Agendamento Rápido: Escolha de serviços com cálculo automático de duração (intervalos de 30 minutos) e preços.
- Atendimento Infantil Especializado: Campos dinâmicos para cadastro do nome e idade da criança e nome do responsável.
- Confirmação via WhatsApp: Integração direta gerando uma mensagem personalizada para o WhatsApp da barbearia com todos os dados da reserva.
- Meus Agendamentos: Painel para o cliente consultar o histórico e gerenciar seus horários informando apenas o número de telefone.

⚙️ Painel Administrativo (Restrito)
- Controle de Status da Loja: Alternância rápida entre "Aberto Agora" e "Fechado no Momento" para controlar novos agendamentos.
- Gestão de Agendamentos: Listagem completa com filtros por status (Pendente, Concluído, Em Atraso, Cancelado).
- Relatório Financeiro: Métricas automáticas de faturamento (Hoje, Esta Semana, Este Mês e Este Ano) e gráfico de distribuição por serviços concluídos.
- Catálogo de Serviços: Cadastro, edição e remoção de serviços com controle de preços e tempo de duração.

🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando tecnologias modernas de desenvolvimento front-end:

- HTML5 & CSS3: Estruturação semântica e estilização customizada.
- Tailwind CSS (via CDN): Design responsivo, moderno e suporte nativo a Modo Escuro / Light Mode.
- JavaScript (Vanilla): Lógica da aplicação, manipulação do DOM e gerenciamento de estado em tempo real.
- FontAwesome: Ícones vetoriais interativos.
